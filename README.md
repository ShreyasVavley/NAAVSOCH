# Naavsoch Studio — Creative Agency & Digital Marketing Platform

[![Tailwind CSS](https://img.shields.io/badge/Tailwind-CSS-38B2AC?style=flat-square&logo=tailwind-css&logoColor=white)](https://tailwindcss.com)

A high-performance, commercial digital marketing and creative agency web platform engineered with **Next.js 15 App Router**, **TypeScript**, and **Tailwind CSS**. Designed for agency brand presentation, showcasing client case studies, dynamic inquiry routing, and smooth cinematic interactive experiences.

---

## ⚡ Key Architectural Features

- **Modular Component Architecture:** Atomic, reusable UI components for dynamic case studies, client portfolios, and interactive brand showcases.
- **Dynamic Routing & ISR:** Incremental Static Regeneration for sub-second page loads and optimized search engine indexing (SEO).
- **Responsive Mobile First UX:** Tailored for cinematic presentation across mobile, tablet, and high-resolution desktop displays.
- **Client Inquiry Pipeline:** Integrated contact and onboarding workflows with secure form validation and notification triggers.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 15 (React 19, App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, Framer Motion
- **Deployment:** Vercel Global Edge Network

---

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/ShreyasVavley/NAAVSOCH.git

# Navigate to project directory
cd NAAVSOCH

# Install dependencies
npm install

# Run the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
